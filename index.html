04 · Proyecto principal

MAKA OWS 2.0 · Plataforma integral para bodas

Migración de un monolito PHP a una arquitectura de microservicios con foco en escalabilidad, mantenibilidad y despliegue en nube.

Visión
  • SPA con Next.js 14 (SSR) como front principal.
  • 5 microservicios NestJS desacoplados (Auth, Evento, Inventario, Servicio, Notificación).
  • PostgreSQL 17 con schemas por servicio.
  • Proyecto académico de 6 meses, equipo de 5, presupuesto cero (free tier cloud).
Arquitectura
Auth · 3001 Evento · 3003 Inventario · 3004 Servicio · 3005 Notificación · 3006

Roles: ADMIN, STAFF, CLIENTE. Estados de evento: PENDIENTE, CONFIRMADO, etc.

Stack
  • Backend: NestJS, TypeScript, módulos + controladores + servicios + DTOs + Pipes.
  • ORM: Prisma 7, migraciones y tipado seguro.
  • Frontend: Next.js 14 App Router, Server/Client Components, Tailwind CSS.
  • Estado: Zustand; data-fetching y caché con TanStack Query.
Infra & DevOps
  • Docker para entornos reproducibles; docker-compose para orquestar servicios y DB.
  • Volúmenes para PostgreSQL y caché de Prisma.
  • Despliegue: Backend en AWS EC2; Frontend en Vercel (GitLab CI/CD); DB en AWS RDS.
Seguridad
  • JWT con Access (15m) y Refresh (7d).
  • Contraseñas hasheadas con Bcrypt.
  • Guards y RBAC por rol; endpoints protegidos por servicio.
Trabajo
  • Git Flow + Conventional Commits.
  • Sprints semanales, dailies y code reviews obligatorias.
  • Testing: Jest/NestJS en backend; Testing Library en frontend.
Troubleshooting
  • Puertos ocupados: liberar procesos o reasignar en compose.
  • Prisma "Client not generated": ejecutar npx prisma generate.
  • "JWT malformed": verificar JWT_SECRET consistente entre servicios.
